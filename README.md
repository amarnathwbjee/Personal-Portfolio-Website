# Personal Portfolio Website

A responsive personal portfolio page by **Amarnath Kumar**, built for the HTML & CSS internship project.

**Live demo:** https://amarnathwbjee.github.io/Personal-Portfolio-Website/

## Technologies
HTML5 and CSS3 (Flexbox, Grid, CSS variables, media queries). No JavaScript, frameworks, backend or database.

## Features
- Sticky navigation bar with anchor links
- Hero section with call-to-action buttons
- About, Skills (6 chips) and Projects (3 cards) sections
- Contact section with email, GitHub and LinkedIn links
- Hover and focus states on links, buttons and cards
- Responsive layout with no horizontal scrolling on mobile

## Run locally
1. Download or clone this repository.
2. Open `index.html` in Chrome or Edge.

Optional local server: `python -m http.server 8000`, then visit http://localhost:8000
