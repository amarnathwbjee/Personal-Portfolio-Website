# Personal-Portfolio-Website
Responsive personal portfolio website built with semantic HTML5 and CSS3 (Flexbox, Grid, CSS variables). No JavaScript or frameworks.


## Technologies
HTML5, CSS3 (Flexbox, Grid, CSS variables, media queries). No JavaScript, frameworks, backend or database.

## Setup and run
1. Download or unzip the folder `YourName_HTML_CSS_Portfolio`.
2. Open `index.html` by double-clicking it, or in VS Code right-click it and choose "Open with Live Server" (optional extension).
3. Alternatively, run a local server from the folder:
   `python -m http.server 8000`, then visit http://localhost:8000

## Customise before submitting
- In `index.html`, replace the sample name (Aarav Sharma), education, projects, email and profile links with your own.
- Do not include your home address or identity documents.

## Test checklist
- Click every navigation link; each jumps to the right section.
- Resize the browser (or use DevTools device mode) to about 375px wide; there should be no horizontal scrollbar.
- Check spelling, contrast and spacing.

## Screenshots
Save a desktop screenshot as `screenshots/desktop.png` and a mobile screenshot as `screenshots/mobile.png`
(Chrome DevTools: F12, then Ctrl+Shift+P, then "Capture screenshot").

## Sample project description (for the submission form)
This is a responsive personal portfolio website built with semantic HTML5 and CSS3 only. It has a sticky navigation bar, a hero section, an About section, six skill chips and three project cards. Layouts use CSS Grid and Flexbox, colours are managed with CSS variables, and buttons, links and cards have hover and focus states. A media query reorganises the layout for tablet and mobile screens without horizontal scrolling.
